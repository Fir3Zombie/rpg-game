Game is a work in progress
Zelda RPG style game.
Story undefined. (still thinking of one)
Controls:
W = move up
S = move down
A = move left
D = move right
E = attack
The main enemy at this point doesn’t have a movement animation so it's sprite just changes from one sprite to a random one as a way to show it has animation.
The map sprites where not made by me, i plan on making my own map design but i didn't have enough time too so i plan on making them this upcoming week.
